# term-menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A zsh + fzf launcher shown by ghostty on every new terminal window, offering Herdr, Tmux, a plain shell, or SSH into any `~/.ssh/config` host.

**Architecture:** One zsh script `tmenu` with pure, sourceable functions (`tmenu_hosts`, `tmenu_entries`, `tmenu_dispatch`) and a `main()` guarded so tests can `source` the file without side effects. Ghostty's `command =` line is replaced by `install.sh` to launch `tmenu`; the script execs the chosen destination.

**Tech Stack:** zsh (shebang `/bin/zsh`, macOS builtin), fzf (runtime dependency, already installed), POSIX sh for `install.sh`, plain-zsh test harness (no bats).

## Global Constraints

- zsh script; shebang `#!/bin/zsh`; script must be `source`-able for tests without running `main`.
- fzf missing -> print one-line notice to stderr, `exec /bin/zsh -il`. Never block terminal use.
- Selection dispatch: `tmux` -> `exec tmux new -A`; `ssh: <host>` -> `exec ssh <host>` (both close window on quit); `herdr` -> run `herdr`, then `exec /bin/zsh -il`; `shell` and empty/unknown selection -> `exec /bin/zsh -il`.
- SSH hosts parsed from `~/.ssh/config` (override: `SSH_CONFIG_FILE`): `Host` lines only, strip trailing comments, skip tokens containing `*`, `?`, or `!`, split multi-name lines, `sort -u`.
- Entry order: `herdr`, `tmux`, `shell`, then `ssh: <host>` per host. Omit `herdr`/`tmux` entries when the binary is not on PATH.
- PATH insurance at top of `main`: prepend `$HOME/.local/bin` and `/opt/homebrew/bin`.
- `TMENU_SKIP=1` -> skip menu, `exec /bin/zsh -il`.
- Ghostty config path: `$HOME/Library/Application Support/com.mitchellh.ghostty/config.ghostty` (override: `GHOSTTY_CONFIG`); symlink dir override: `TMENU_BIN_DIR` (default `$HOME/.local/bin`). Keep the existing `env = PATH=...` line untouched.
- No `.zshrc` hook. No tmux/herdr/SSH session guards needed.
- Tests: plain zsh harness, fixtures under `tests/fixtures/`, run with `tests/run.sh` (exit 1 on any failure).

#!/bin/zsh
# term-menu: destination picker for new terminal windows.

tmenu_hosts() {
  local config="${SSH_CONFIG_FILE:-$HOME/.ssh/config}"
  [[ -r "$config" ]] || return 0
  local line rest h
  while IFS= read -r line; do
    line="${line%%\#*}"                                  # strip comments
    [[ "$line" =~ ^[[:space:]]*Host[[:space:]] ]] || continue
    rest="${line#*Host}"
    for h in ${=rest}; do                                # split multi-name lines
      [[ "$h" == *'*'* || "$h" == *'?'* || "$h" == *'!'* ]] && continue
      print -r -- "$h"
    done
  done < "$config" | sort -u
}

if [[ ${ZSH_EVAL_CONTEXT} == toplevel ]]; then
  main() { :; }
  main "$@"
fi
```

Note: `main` is a placeholder here; Task 3 replaces it. The `ZSH_EVAL_CONTEXT == toplevel` guard is what lets tests `source` this file without executing anything: direct execution reports `toplevel`, sourcing reports `toplevel:file` (zsh rewrites `$0` to the sourced file's path, so a `basename $0` guard would misfire).

tmenu_dispatch() {
  local sel="$1" mode="${2:-run}"
  if [[ "$mode" == print ]]; then
    case "$sel" in
      herdr)   print -r -- "herdr; exec /bin/zsh -il" ;;
      tmux)    print -r -- "exec tmux new -A" ;;
      shell)   print -r -- "exec /bin/zsh -il" ;;
      ssh:\ *) print -r -- "exec ssh ${sel#ssh: }" ;;
      *)       print -r -- "exec /bin/zsh -il" ;;
    esac
    return 0
  fi
  case "$sel" in
    herdr)   herdr; exec /bin/zsh -il ;;
    tmux)    exec tmux new -A ;;
    shell)   exec /bin/zsh -il ;;
    ssh:\ *) exec ssh "${sel#ssh: }" ;;
    *)       exec /bin/zsh -il ;;
  esac
}

main() {
  export PATH="$HOME/.local/bin:/opt/homebrew/bin:$PATH"
  if [[ "${1:-}" == --print ]]; then
    tmenu_dispatch "${2:-shell}" print
    return $?
  fi
  if [[ "${TMENU_SKIP:-0}" == 1 ]]; then
    exec /bin/zsh -il
  fi
  if ! command -v fzf >/dev/null 2>&1; then
    print -u2 "tmenu: fzf not found; starting plain shell"
    exec /bin/zsh -il
  fi
  local sel
  if ! sel="$(tmenu_entries | fzf --height=100% --border --no-multi \
      --header='herdr  tmux  shell  ssh: <host>   (Esc = plain shell)' \
      --prompt='Open: ')"; then
    exec /bin/zsh -il
  fi
  tmenu_dispatch "$sel"
}

if [[ ${ZSH_EVAL_CONTEXT} == toplevel ]]; then
  main "$@"
fi
```

#!/bin/sh
set -eu

REPO_DIR="$(cd "$(dirname "$0")" && pwd)"
BIN_DIR="${TMENU_BIN_DIR:-$HOME/.local/bin}"
CONFIG="${GHOSTTY_CONFIG:-$HOME/Library/Application Support/com.mitchellh.ghostty/config.ghostty}"
MENU_BIN="$BIN_DIR/tmenu"

mkdir -p "$BIN_DIR"
ln -sf "$REPO_DIR/tmenu" "$MENU_BIN"

if [ ! -f "$CONFIG" ]; then
  echo "error: ghostty config not found: $CONFIG" >&2
  exit 1
fi

cp "$CONFIG" "$CONFIG.bak-tmenu"

if grep -q "^command = .*ghostty-herdr-session" "$CONFIG"; then
  sed -i '' "s|^command = .*ghostty-herdr-session|command = $MENU_BIN|" "$CONFIG"
elif grep -q "^command = $MENU_BIN" "$CONFIG"; then
  : # already installed; keep idempotent
else
  echo "error: no 'command =' line to replace in $CONFIG" >&2
  exit 1
fi

echo "installed: $MENU_BIN -> command = $MENU_BIN"
```

```markdown
# term-menu

Destination picker for new terminal windows. Every ghostty window opens a menu:
Herdr, Tmux, a plain shell, or SSH into any host in `~/.ssh/config`.

## Install

```sh
./install.sh
```

- Symlinks `tmenu` to `~/.local/bin/tmenu`.
- Replaces the `command =` line in the ghostty config
  (`~/Library/Application Support/com.mitchellh.ghostty/config.ghostty`) with
  `command = ~/.local/bin/tmenu`, keeping a backup at `config.ghostty.bak-tmenu`.
- Idempotent; the `env = PATH=...` line is left untouched.

Restart ghostty (or open a new window). To restore the old behavior, point
`command =` back at `ghostty-herdr-session` (see the backup file) and remove
the `~/.local/bin/tmenu` symlink.

## Menu

| Entry        | Action                                             |
| ------------ | -------------------------------------------------- |
| `herdr`      | Launch/attach Herdr; returns to a zsh prompt after detach |
| `tmux`       | `tmux new -A` (attach most-recent session, else create); quitting closes the window |
| `shell`      | Fresh interactive login zsh                        |
| `ssh: <host>`| `ssh <host>`; quitting closes the window          |

Esc or Ctrl-C lands on a plain shell. Set `TMENU_SKIP=1` (e.g. a second ghostty
profile, or `ghostty -e env TMENU_SKIP=1 tmenu`) to skip the menu entirely.

## Requirements

zsh, fzf, tmux, herdr (the menu omits entries for missing binaries). Hosts come
from `~/.ssh/config`; pattern hosts (`*`, `?`, `!`) are skipped.
```
